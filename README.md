# vite-tahoe-ui

Bringing Apple's Liquid Glass design language from macOS Tahoe to the web — a living showcase of translucent, depth-rich interface elements you can explore right in the browser.

## Design Philosophy

Tahoe UI recreates the stunning visual language Apple introduced in macOS Tahoe — Liquid Glass. Built around translucent materials, soft lighting, and refined motion, interface elements appear to float above content with a sense of depth and clarity.

## Features

- **Liquid Glass Effect** — Authentic frosted glass materials that respond dynamically to background content
- **Tahoe-Style Components** — Windows, buttons, inputs, menus, dialogs, and more
- **Native macOS Experience** — Traffic light controls, sidebars, scrollbars — everything feels familiar
- **Dark Mode** — Automatic adaptation to system theme preferences
- **Modern Stack** — React + TypeScript + Vite
